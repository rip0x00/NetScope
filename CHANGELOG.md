### Added

- Project foundation: architecture documentation and decision records
  (ADR-001 to ADR-006), including the recorded deviations for Android
  (framework Kotlin via the manual build pipeline) and Apple platforms
  (documentation only until a macOS build host exists).
- Shared data contracts: `diagnostic-result` and `report` JSON Schemas
  (draft 2020-12) in `shared/schemas/`.
- Brand identity: original reticle mark in seven SVG variants and
  machine-readable design tokens in `assets/branding/`.
- Design system: dark and light palettes with measured contrast ratios,
  typography, spacing, iconography, motion, and accessibility rules in
  `docs/design/DESIGN_SYSTEM.md`.
- Project tracking: capability audit and platform matrix in
  `PROJECT_STATUS.md`, roadmap, and development log.
