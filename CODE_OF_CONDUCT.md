# Code of Conduct

This project follows the Contributor Covenant, version 2.1, in summary:

- Be respectful and constructive. Harassment, discrimination, and personal
  attacks are not tolerated in any project space.
- Assume good faith in technical disagreement; criticise work, not people.
- Maintainers may remove content and, where necessary, restrict
  participation to keep project spaces usable for everyone.

The full text of the Contributor Covenant 2.1 is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and is
incorporated by reference. Reports about conduct can be made privately to
the maintainers through the repository's GitHub organisation contacts.
